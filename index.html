Cara ambil API key Roblox
  1. Buka create.roblox.com/dashboard/credentials
  2. Klik Create API Key
  3. Di Access Permissions, tambahkan API System Assets → centang Read dan Write
  4. Batasi ke User/Group ID kamu di bagian Security
  5. Simpan, lalu copy key (cuma muncul sekali)
